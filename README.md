# Studying-IAC

infrastructure as code (iac) is an approach that allows infrastructure resources to be defined, configured, and managed through code instead of manually setting them up through cloud service dashboards.

with terraform, i can describe the resources i want to create and use providers to provision and manage them across different cloud platforms.

the purpose of this repository is to practice iac concepts, understand how terraform works, and explore some of the main cloud platforms.

## Technologies and cloud providers

- **terraform:** tool used to define and manage infrastructure as code.
- **aws (amazon web services):** studying resource provisioning using the `aws` provider, including storage with s3.
- **azure (microsoft azure):** studying resource provisioning using the `azurerm` provider, including resource groups and virtual networks.
- **gcp (google cloud platform):** studying resource provisioning using the `google` provider, including virtual machines with compute engine.
